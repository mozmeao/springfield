Headings use six sizes. Each heading element shares a size with a class, and every size follows the page's type scale.

| Size | Element | Regular | Compact | Width | Line-height |
|---|---|---|---|---|---|
| `.fl-heading-display` | — | 40 / 56 / 80 | 32 / 48 / 64 | Condensed | 0.9 |
| `.fl-heading-xl` | `h1` | 40 / 56 / 64 | 32 / 36 / 48 | Condensed | 0.9 |
| `.fl-heading-lg` | `h2` | 32 / 40 / 56 | 24 / 32 / 40 | Condensed | 0.9 |
| `.fl-heading-md` | `h3` | 24 / 24 / 32 | 20 / 24 / 28 | Normal | 1.2 |
| `.fl-heading-sm` | `h4`, `h5`, `h6` | 18 / 18 / 24 | 16 / 18 / 20 | Normal | 1.2 |
| `.fl-heading-xs` | — | 16 / 16 / 16 | 16 / 16 / 16 | Normal | 1.2 |

Sizes are px for phone (below 600) / tablet (600–899) / desktop (900 and up).

See CSS conventions in Docs for which headings take a size class and how pages choose a scale.

Enterprise pages always use Compact. Display, xl and lg are normal width, weight 400 and -0.02em letter-spacing; md and smaller keep weight 600 and no letter-spacing.
