The `badge` component is one milestone in the referral Impact Dashboard: optional decorative artwork, a badge name, and a number of installs with its label. It only appears inside the `impact-dash` list, rendered by the Impact dashboard block in a Showcase tab.

A badge is achieved once the referrer's install count reaches its **number**. Only the Referral Hub page supplies that count, so on any other page every badge stays locked. The artwork in the `media` slot is hidden from screen readers — the number and label carry the meaning.
