The `topic` component is one anchored section of a Topic List: an image, a heading, rich text and up to three stacked buttons. The list adds a sidebar of links on desktop, which highlights the topic in view, and a menu of the same links on mobile.

It's the Topic List block on free-form pages, for long pages where readers jump between sections. Each topic needs an **anchor_id** and a **short_title** for its sidebar link. Keep those titles short and parallel in grammatical structure so the list scans cleanly.
