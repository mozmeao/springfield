The `resources` component arranges columns of links, each under its own heading — for directories, the end of long pages, or any set of destinations that reads better grouped. It's the Resources block, in Sections and as a free-form page section.

Add a subheading to split a column into labelled groups. Each subheading closes the list above it and starts a new one, so the groups stay separate for screen readers as well as visually. Column headings follow the page outline, and subheadings sit one level below.
