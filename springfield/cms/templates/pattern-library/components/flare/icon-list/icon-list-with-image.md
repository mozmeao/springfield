Icon List with Image pairs an `icon-list` with a supporting image, in the narrow `media-content` layout with the image first. It's the Icon List with Image block, in Sections and Featured Image Sections, and has no layout settings.

It suits product walkthroughs, capability checklists and why-us sections anchored by one visual. Keep the list to 4–6 items so the columns stay balanced. The image needs alt text unless it's marked decorative.
