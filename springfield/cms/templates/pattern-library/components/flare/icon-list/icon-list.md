The `icon-list` component is a list of short items, each led by an icon. It flows into two columns when the container is wide enough. The icons are hidden from screen readers, so the text has to carry the meaning on its own.

Editors add it as an Icon List inside a Two Column Card, and it's also the list in the Icon List with Image block. Pick icons that reinforce each item rather than decorate it, and keep items to a line or two so the columns stay even.
