The `comparison-image-header` component is a column header in the Browser Comparison Table: an image, usually a browser logo, above a short label. Editors add it through a cell's Optional content → Image header, normally in the header row; there's no standalone block.

Leave the image's alt text empty when the label already names it, so screen readers don't hear it twice. An optional dark-mode image swaps in when the visitor's system uses dark mode.
