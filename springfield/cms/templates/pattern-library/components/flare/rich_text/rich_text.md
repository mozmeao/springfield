The `rich_text` component wraps prose in `fl-rich-text`, Flare's long-form type styles: headings, lists, quotes, code blocks, links and images, rendered here from a markdown file of examples.

Article and blog pages, the Flare Docs changelog and contact form help text apply the class directly. Rich text inside CMS blocks uses the simpler `fl-body` styles instead, so this sample is the reference for article-style content rather than block copy.
