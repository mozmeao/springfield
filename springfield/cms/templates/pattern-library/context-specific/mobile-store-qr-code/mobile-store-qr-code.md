The `mobile-store-qr-code` component promotes the Firefox mobile app with a heading and a QR code for a URL the editor sets, usually the mobile download page. On iOS and Android it swaps the QR code for a mobile image and App Store and Google Play buttons.

It's the Mobile Store Button / QR Code block on free-form pages. Editors set the **QR code data** — the URL to encode — and a mobile image, whose alt text is required unless it's decorative. Use it on pages that promote the mobile app to desktop visitors.
