The referral download CTA is the download button on the referral Get Firefox page: a direct download on Windows and macOS, the thanks page on Linux, and store badges on Android and iOS. A consent checkbox counts the install as a referral; it stays hidden until the page's script reveals and checks it, and only shows on Windows, macOS and Android — never on iOS or Linux.

Editors add it as the Referral Download CTA in the Kit Intro's first button row, only on the referral Get Firefox page and only once per page. It has no settings — the invitation code comes from the page.
