The `copy-to-clipboard-button` component copies a value — usually a URL — to the clipboard. On success it swaps to a confirmation label and icon, announced to screen readers, and disables itself for two seconds.

There's no block of its own: it's the copy action in Sharing Links, the referral invite controls, the Set-as-Default snippet and the Smart Window page. It does nothing when the value is empty, and each copy is reported to analytics.
